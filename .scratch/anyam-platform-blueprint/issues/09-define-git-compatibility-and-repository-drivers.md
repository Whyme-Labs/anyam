# Define Git compatibility and repository drivers

Type: research
Status: open
Blocked by: 01, 08

## Question

Which Git semantics and transports must Anyam preserve, what cannot be represented by standard Git, and what Repository Driver contract safely supports Cloudflare Artifacts plus credible fallback backends? Decide canonical versus workspace repositories, refs, import/export, anonymous reads, LFS and large objects, mirroring, token granularity, failure recovery, and backend qualification gates.
