# Qualify the execution and runner plane

Type: research
Status: open
Blocked by: 01, 18

## Question

Which workloads can safely and economically run on Cloudflare's managed execution plane, which require external pull runners, and what portable runner protocol covers Linux, macOS, Windows, GPU, ARM, private networks, and hardware? Define isolation, immutable inputs, caching, networking, secret brokerage, job identity, logs, cancellation, artifact upload, evidence, retry, and hostile-workload limits.
