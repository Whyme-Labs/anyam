# Customer-operated RepositoryDriver snapshot adapter

Anyam ships a provider-neutral `apps/repository-driver` Worker as the default customer-operated RepositoryDriver. It reads one provider-synchronized, credential-free snapshot manifest per Repository from the customer’s R2 bucket, accepts requests only from the private RepositoryObserver service binding, and verifies exact Repository/Source Space identity, head, tree, base, object format, ref, and ancestry before returning the existing observation contract. Missing, revoked, explicitly stale, mismatched, malformed, or oversized state remains unavailable or blocked with a recovery receipt. Provider-specific GitHub, Smart-HTTP, and Anyam-native synchronizers stay outside the Realm and can replace the snapshot writer without changing Authority or Observer contracts.
