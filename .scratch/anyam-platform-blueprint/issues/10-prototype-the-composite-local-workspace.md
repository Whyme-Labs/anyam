# Prototype the composite local workspace

Type: prototype
Status: open
Blocked by: 08, 09

## Question

How should the Anyam client materialize several authorized Source Spaces as one coherent local filesystem while preserving standard editor and Git behavior, fast offline iteration, automatic snapshots, unified status/diff, undo, conflict handling, and safe synchronization? Build the cheapest working interaction prototype needed to expose semantic and usability failures.
