# Specify Source Spaces, Project Views, and Project Revisions

Type: prototype
Status: open
Blocked by: 01, 04, 06

## Question

What precise source-state model lets one Project contain independently protected Source Spaces, capability-safe Project Views, and atomic Project Revisions without metadata leakage or incoherent public/private histories? Produce a low-fidelity formal model with invariants, projection rules, dependency closure, failure cases, and concrete open-core scenarios for human review.
